Version control records every change to the data and the code so
anyone can see what was edited and when it was edited, as well as 
roll back when a mistake is made. The automated quality checks test
sales data for accuracy, consistency, and completeness every time
the script runs and the assert statement stops the program if
anything is looking abnormal. Together, these two steps help 
produce credible data.
